# ChatBot Demo 🤖

A modern chatbot application built with Streamlit and powered by Groq API for fast and intelligent conversations.

## 🚀 Live Demo

Try the chatbot here: [https://luqman-chatbot-groq.streamlit.app/](https://luqman-chatbot-groq.streamlit.app/)

## 📋 Features

- 💬 Real-time chat interface
- 🚀 Fast response times powered by Groq
- 🎨 Clean and intuitive user interface
- 📱 Responsive design
- 🔒 Secure API integration

## 🛠️ Technologies Used

- **Frontend**: Streamlit
- **AI/ML**: Groq API
- **Language**: Python
- **Deployment**: Streamlit Cloud

## 🏃‍♂️ Running Locally

1. Clone the repository:
```bash
git clone https://github.com/lululuqman/chatb-bot-demo.git
cd chatb-bot-demo


Install dependencies:

pip install -r requirements.txt


Set up environment variables:

# Create a .env file and add your Groq API key
GROQ_API_KEY=your_groq_api_key_here


Run the application:

streamlit run app.py

📁 Project Structure

chatb-bot-demo/
├── app.py              # Main Streamlit application
├── requirements.txt    # Python dependencies
├── .env               # Environment variables (not tracked)
├── .gitignore         # Git ignore file
└── README.md          # Project documentation

🔧 Configuration

Make sure to obtain a Groq API key from Groq Console and add it to your environment variables.
